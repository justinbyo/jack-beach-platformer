# Jack: Beach Assault

A Mario-style 2D pixel platformer built with plain JavaScript and HTML5 Canvas.

Jack storms a beach full of yellow plumbers, jumps and shoots lasers, smashes mystery boxes for random powers, and dodges falling net traps from palm trees.

## Run locally

```bash
npm start
```

Then open: `http://localhost:5173`

## Controls

- **A / D** or **Left / Right Arrow**: Move
- **W / Up Arrow / Space**: Jump
- **F / J**: Shoot lasers
- **R**: Restart run

## Gameplay

- Stomp enemies by jumping on them.
- Shoot enemies with lasers.
- Hit mystery boxes from below or blast them with lasers to destroy them and gain random powers:
  - Speed Burst
  - Super Jump
  - Rapid Laser
  - Shield
- Watch for random falling net traps from palm trees.
- Reach the flag to clear the beach.
